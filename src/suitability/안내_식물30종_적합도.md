# 식물 30종 적합도 계산·검증 (2026-11-04)

## 무엇을 했나
- `plant_suitability.py`: 유민 추천엔진 규칙(S_sun·S_temp·계절 필터·min)을 그대로 재현해 **A/B/C × 12개월 × 30종 = 1,080행**을 계산. 엔진에 없던 **실내식물 10종**은 조도(lux) 기준 광 점수를 붙여 추가.
- `validate.py`: 실측·사람 평가 없이 계산값과 공개 기준만으로 V1~V6 검증 + 개선안 1개 비교.
- 실행: 이 폴더에서 `python plant_suitability.py` → `python validate.py` (pandas, numpy만 필요). 결과는 `output/`.

## 입력 (input/)
| 파일 | 출처 |
|---|---|
| plant_data.csv | 규연 작물 DB 30종 |
| OBS_ASOS_TIM_서울108.csv | 유민 ASOS 108 매시 자료 (2025-10-01 ~ 2026-09-01) |
| window_sun_monthly_ABC.csv | 유민 노트북의 A/B/C direct_h (sun_weather_monthly.csv 값) + sun.json sun_up_h |
| indoor_lux.csv (선택) | Lux 스레드 결과를 넣으면 임시식 대신 사용. 열: scenario, month, lux_mean |

## 규칙
- 베란다작물 20종: S_sun = min(direct_h / 최소일조시간, 1)×100, S_temp = 21일 매시 기온 24개 중 적정범위 비율×100, 제철 아니면 제외, S_final = min.
- 실내식물 10종: S_light = min(실내 낮 평균 lux / 최소 lux, 1)×100. 실내 lux는 Lux 스레드 결과(building/indoor_lux/indoor_lux.csv, 창에서 1m·화분 높이 0.6m)를 input/indoor_lux.csv로 복사해 사용. 파일이 없을 때만 임시식(ASOS 일사 ×110 lm/W × 직사비율×0.30 + 나머지×0.05). 최대 조도(10000 lx) 초과는 감점하지 않고 '직사 주의'로 표시. 실내 기온 = 외기를 18~28℃로 제한(난방·냉방 가정). 계절 제한 없음.
- 순위는 **베란다작물 / 실내식물 따로** 매김. 한 줄로 섞으면 실내식물이 매달 100점으로 상위를 모두 차지해서.
- 등급: 80 이상 적합, 50 이상 보통, 그 미만 부적합.

## 출력 (output/)
- suitability_30.csv: 전체 1,080행 (S_light, S_temp, S_final, 제한요인, 순위, 등급, 근거 문구)
- top3_by_month.csv: 시나리오·월·그룹별 상위 3 (동점 포함)
- start_months.csv: 작물별 '적합' 첫 달과 적합 달 목록
- validation_summary.txt, validation_sensitivity.csv, validation_calendar.csv, variant_trapezoid.csv

### 개선안 비교 (엔진은 바꾸지 않았음, 참고용)
S_temp를 "그 달 일평균기온 평균 + 사다리꼴(범위 밖 5℃에서 0점)"으로 바꾸면 V6 적기 일치율이 **31% → 63%**(C 26% → 55%)로 오름. 대신 공동 1위가 평균 4.9종으로 늘어 동점 정리 규칙(예: 광 점수 여유, 범위 중앙과의 거리)이 같이 필요. 메모리의 향후 계획(EcoCrop min/opt/max 온도 반응)과 같은 방향.

## 한계·확인할 것
1. 재배달력 기준(validate.py의 CALENDAR)은 중부지방 일반 파종·정식 적기를 적은 **초안**. 농사로 작목별 재배력으로 대조해 확정해야 발표 근거로 쓸 수 있음.
2. 실내식물 광 점수는 Lux 스레드 값(1m 지점)으로 교체 완료. A·B는 12개월 모두 1500 lx 이상이라 광 제한이 없고, C에서만 골드크레스트가 11~1월 광 제한(82~93점). 요구량 300/800/1500 lx는 생존·유지 수준이라 실내식물 점수는 주로 기온범위로 정해짐.
3. plant_data.csv 실내식물 기온범위가 좁음 (몬스테라·금전수 16~20℃, 산세베리아 21~25℃). 일반 원예 자료보다 좁아 보여서 여름·겨울 점수가 낮게 나옴. 출처 확인 필요.
4. A 시나리오 direct_h는 유민 노트북 값(대명루첸 101동 기준). 이후 juso DSM 재계산 값이나 A-2 7세대 값이 있으면 window_sun_monthly_ABC.csv만 바꿔 다시 돌리면 됨.
