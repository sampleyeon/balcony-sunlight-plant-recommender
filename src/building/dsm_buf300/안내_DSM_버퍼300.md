# 성북구 경계 + 300m 버퍼 DSM 재제작 (다음 단계 1번)

결과물: `C:\gis\`
- `seongbuk_buf300.gpkg` 안 `buildings_buf300_202609`(필드 `h`, `ym`, `in_sb`, `h_src`), `boundary`, `buffer300`
- `dsm_buf300_202609.tif` (EPSG:5186, 2m, Float32, 빈 땅 0, NoData 없음, 기존 `dsm_202609.tif`와 같은 격자)

기존 파일은 건드리지 않습니다. 성북구는 서울 안 구들(종로·동대문·중랑·노원·강북)과만 맞닿아 있어서 서울 GIS건물통합정보 shp 하나로 300m 버퍼가 다 채워집니다.

## 1단계. 성북구 경계 파일 받기 (권장)

1. 브라우저에서 V-World(vworld.kr) 또는 국가공간정보포털에서 **"시군구 경계"**(행정구역 시군구, 법정구역 시군구 등)를 검색해 **서울 SHP**를 내려받습니다.
2. 압축을 `C:\gis\boundary\`에 풉니다.
3. QGIS 메뉴 **레이어 → 레이어 추가 → 벡터 레이어 추가** → 소스에서 `.shp` 선택 → **추가**. 성북구 모양이 제대로 나오는지만 확인합니다.
   - 한글이 깨지면 레이어 우클릭 → **속성 → 소스 → 데이터 소스 인코딩**을 `CP949`(또는 `EUC-KR`)로 바꿉니다. 스크립트는 코드 `11290`으로도 찾으니 깨져도 진행에는 문제없습니다.
   - 좌표계가 5186이 아니어도 됩니다. 스크립트가 5186으로 변환합니다.

경계 파일을 구하기 어려우면 이 단계는 건너뛰세요. 스크립트가 성북구 건물들의 볼록껍질을 경계 대신 씁니다(실제보다 조금 넓게 잡혀서 건물이 더 들어가지만 결과에는 해가 없습니다).

## 2단계. 스크립트 실행

1. `make_dsm_buf300.py`를 `C:\gis\`에 저장합니다.
2. **플러그인 → 파이썬 콘솔** → 콘솔 위쪽 아이콘 중 **편집기 표시**(종이+연필 모양) → 편집기 쪽 **열기**(폴더 아이콘) → `make_dsm_buf300.py`.
3. 편집기 맨 위 `여기만 확인하세요` 부분:
   - `BOUNDARY = r'C:\gis\boundary\파일이름.shp'` (1단계를 건너뛰었으면 `r''` 그대로)
   - 서울 건물 shp는 `gis` 폴더 아래에서 `AL_D010_11_20260909*.shp`를 자동으로 찾습니다. 못 찾는다고 나오면 `SEOUL_SHP`에 경로를 넣으세요.
4. 편집기의 **▶ 스크립트 실행**을 누릅니다. 서울 전체 건물을 읽어서 몇 분 걸릴 수 있습니다. 끝나면 콘솔에 `[buf300] 완료`가 찍히고 레이어 4개가 추가됩니다.

## 3단계. 확인 (콘솔 출력 + 화면)

콘솔에서 볼 것:
- `NoData=None` 이어야 합니다. (NoData가 0이면 UMEP 오류)
- `기존 범위 안` 줄에서 `값이 줄어든 픽셀` 이 0이거나 아주 작아야 합니다. 기존 DSM 사각형 범위에도 이웃 구 건물 자리가 0으로 들어 있었으므로, 달라진 픽셀은 대부분 `0→건물로 새로 채워진 픽셀` 이어야 합니다.
- `성북구 안 A16 …% / A26x3 …% / default3 …%` 는 다음 단계 3번(높이 추정 건물 비율)의 답이니 적어두세요.

화면에서 볼 것:
1. `dsm_buf300_202609` 우클릭 → **속성 → 심볼로지** → 렌더 유형 **단일밴드 의사색상**, 최소 0 / 최대 50 정도 → **확인**.
2. `buffer300` 우클릭 → 속성 → 심볼로지 → **단순 채우기**에서 채우기 스타일 **브러시 없음**, 선 색 빨강 → 확인. `boundary`도 같은 방식으로 파란 선.
3. 빨간 선과 파란 선 사이(성북구 밖 300m)에 건물 높이가 채워져 있는지 봅니다.
4. 상단 도구 **피처 식별**(i 아이콘)로 성북구 밖 건물 위 DSM 픽셀을 클릭해 값이 그 건물 `h`와 같은지 봅니다.
5. 레이어 우클릭 → **속성 → 정보** 탭에서 크기·픽셀 크기 2m·좌표계 EPSG:5186 확인.
6. **프로젝트 → 저장**(`seongbuk.qgz`).

## 참고

- 그림자 12개월(`shadow\2510`~`2609`)은 기존 DSM으로 만든 것이라 성북구 경계 근처는 여전히 햇빛 과대입니다. 새 DSM으로 다시 돌리려면 UMEP Shadow Generator에서 DSM만 `dsm_buf300_202609`로 바꾸고 나머지 설정(UTC +09:00, 서머타임 해제, 30분, 매달 21일)은 그대로 두면 됩니다. 범위가 넓어진 만큼 시간이 더 걸립니다.
- 스크립트를 다시 실행해도 됩니다. 이전 결과 레이어를 프로젝트에서 빼고 덮어씁니다.
