# 3D 건물 + 시간별 그림자 보기 (QGIS 3D 맵 뷰)

건물을 높이 `h`만큼 세운 3D 지도 바닥에 UMEP 그림자를 깔고, 시간 컨트롤러로 07:00 → 17:30을 30분씩 넘기며 보는 방법입니다. 스크립트 하나가 레이어, 3D 모양, 시간 설정을 모두 해 줍니다.

## 준비물 (gis 폴더 `C:\gis`)
- `seongbuk_buf300.gpkg` (건물, 높이 h)
- UMEP 그림자 `Shadow_YYYYMMDD_HHMM_LST.tif` (gis 폴더 아래 어디에 있어도 찾음)
- `shadow_3d.py` (이 파일 옆)를 gis 폴더에 복사

## 1. 스크립트 실행
1. QGIS에서 새 프로젝트를 엽니다. (기존 프로젝트에서 해도 됩니다)
2. 플러그인 → 파이썬 콘솔 → 편집기 표시 → 열기 → `shadow_3d.py` → ▶
3. 콘솔에서 확인할 것:
   - `[3d] 그림자: 20251021, 22장 (0700 ~ 1730)`
   - `[3d] 그림자 격자 폭 4079 → 건물: old`
   - `[3d] 3D 건물 40xxx동`
   - `[3d] 완료.`
4. 레이어 패널 맨 위에 `3D 그림자` 그룹이 생깁니다. 2D 지도에 12:30 그림자(남색)가 보이면 정상입니다.

## 2. 3D 창 열기
1. 메뉴 **보기 → 3D 맵 뷰 → 새 3D 맵 뷰** (단축키 Ctrl+Alt+M)
2. 새 창에 건물이 세워진 지도가 뜹니다. 처음엔 위에서 내려다본 모습입니다.
3. 마우스 조작
   - 왼쪽 드래그: 지도 이동
   - 휠: 확대/축소
   - **Shift + 왼쪽 드래그** (또는 휠 버튼 드래그): 기울이기·돌리기 → 비스듬히 내려다보게 만드세요
4. 창이 작으면 3D 창 제목줄을 끌어 따로 띄우거나 크게 키웁니다.

## 3. 시간 돌리기
1. 메뉴 **보기 → 패널 → 시간 컨트롤러** (지도 툴바의 시계 아이콘도 같음)
2. 시간 컨트롤러가 이미 "애니메이션" 모드, 2025-10-21 07:00 ~ 18:00, 30분 간격으로 맞춰져 있습니다.
3. ▶ 를 누르면 2D 지도와 3D 창의 그림자가 30분씩 바뀝니다. ◀ ▶ 한 칸 버튼으로 한 장씩 넘길 수도 있습니다.
4. 빠르기는 시간 컨트롤러 오른쪽 톱니(설정) → 초당 프레임 수에서 바꿉니다. (기본 2장/초)

## 4. 발표용 영상 만들기
- 3D 창을 원하는 각도로 맞춘 뒤 시간 컨트롤러 ▶ 를 누르고 화면을 녹화합니다.
  - Windows: **Win + Alt + R** (Xbox Game Bar 녹화) 또는 캡처 도구 → 녹화
- 길음뉴타운처럼 한 곳만 크게 보여 주려면 `FOCUS = (201540, 556482, 700)`처럼 중심 좌표(EPSG:5186)와 반경(m)을 넣고 다시 실행합니다. 건물 수가 줄어 3D도 훨씬 빨라집니다.

## 알아 둘 점
- **지금 그림자는 예전 DSM(dsm_202609, 성북구만)으로 만든 것**입니다. 그래서 스크립트가 같은 건물(성북구 건물, `in_sb = 1`)만 세웁니다. 재개발 신축 단지(꿈의숲아이파크 등)는 건물도 그림자도 빠져 있고, 옛 주택이 그 자리에 있습니다.
- 신축 단지까지 보려면: UMEP Shadow Generator를 예전과 같은 설정으로 `dsm_buf300_juso_202609.tif`에 다시 돌려 새 폴더(예: `gis\shadow_juso\`)에 저장하고, `SHADOW_DIR`을 그 폴더로 바꿔 다시 실행합니다. 격자가 달라 스크립트가 자동으로 `juso` 건물(신축 반영, 옛 건물 제거)을 고릅니다.
- 그림자는 땅에 드리운 그림자만 보입니다. 건물 벽·옥상에 지는 그림자는 3D로 칠해지지 않습니다. 건물은 연한 회색으로 서 있고, 바닥의 남색이 그 시각의 그림자입니다.
- 바탕의 OpenStreetMap은 인터넷이 필요합니다. 필요 없으면 `BASEMAP = False`.
- 다시 실행하면 이전 `3D 그림자` 그룹을 지우고 새로 만듭니다. 3D 창은 그대로 두어도 됩니다.

## 이렇게 되면
- 3D 창의 그림자가 시간에 따라 안 바뀜: 3D 창을 닫고 시간 컨트롤러를 ▶ 한 상태에서 새 3D 맵 뷰를 다시 엽니다.
- 3D 창에 건물이 납작함: 레이어 `건물 3D (높이 h)` 오른쪽 클릭 → 속성 → 3D 뷰 에서 "단일 심볼"·돌출 높이 옆 데이터 정의 버튼이 `h`인지 확인합니다.
- 너무 느림: `FOCUS`로 범위를 줄이세요.
- 오류가 나면 콘솔 마지막 몇 줄을 캡처해서 보내 주세요.
