# 창 Lux(실내 조도) 포함해서 다시 계산하기

순서는 **window_sun_final.py → indoor_lux.py** 두 번 실행이 전부입니다. 최종 시나리오(2026-11-08): A 꿈의숲아이파크 709동 18층 남동, B 돈암풍림 103동 4층 남, C 길음뉴타운8단지래미안 805동 1층 남. 둘 다 QGIS 파이썬 콘솔에서 돌리고, 결과는 모두 `C:\gis` 폴더에 생깁니다.

## 0. 준비 (처음 한 번)
공유 폴더에서 두 파일을 받아 `gis` 폴더에 넣습니다.
- `building/indoor_lux/indoor_lux.py`
- `building/window_sun/window_sun_final.py` (최종 시나리오 A·B·C가 들어 있는 직사광 계산)
- `building/indoor_lux/OBS_ASOS_TIM_202610121318479_30.csv` (팀원이 전처리한 기상청 시간별 자료, 2025-10~2026-09 12개월 전체). gis 폴더에 예전 `OBS_ASOS_TIM_서울108.csv`가 있으면 빼 두세요(9월이 없는 파일)

## 1. 직사광 계산
1. QGIS → 플러그인 → 파이썬 콘솔 → 편집기 표시 → 열기 → `window_sun_final.py` → ▶
   - 콘솔에 `A: 주소로 찾음 ... 709동`, `C: 주소로 찾음 ... 805동`이 나오는지 봅니다. B(돈암풍림 103동)는 전자지도에 없어서 `서울 건물 파일로 찾습니다`가 나오는 게 정상입니다.
   - `dsm_buf300_juso_202609.tif`(신축 단지 포함 DSM)가 gis 폴더에 있어야 A 709동이 계산됩니다.
2. 끝나면 gis 폴더에 두 파일이 새로 생겼는지 봅니다.
   - `window_sun_monthly.csv` (월별 직사광 시간)
   - `window_sun_detail.csv` (10분마다 햇빛 들어옴 1 / 안 들어옴 0) ← 실내 조도 계산이 이 파일을 씁니다

## 2. 실내 조도 계산 (새로 추가)
1. 같은 편집기에서 열기 → `indoor_lux.py` → ▶ (1초 안에 끝납니다)
2. 콘솔에서 이 세 줄을 확인합니다.
   - `월별 직사광: C:\gis\window_sun_monthly.csv`
   - `10분 판정  : C:\gis\window_sun_detail.csv` ← 여기가 `없음`이면 1단계를 먼저 돌리세요
   - `저장: ...\indoor_lux.csv 36 행`
3. 결과 파일
   - `indoor_lux.csv`: 창에서 1m 지점, 시나리오별 12개월 (식물 적합도 계산에 쓰는 파일)
   - `indoor_lux_positions.csv`: 창가 / 1m / 2m / 3m 전체

## 3. 보내 주실 파일
gis 폴더의 4개 파일을 올려 주세요: `window_sun_monthly.csv`, `window_sun_detail.csv`, `indoor_lux.csv`, `indoor_lux_positions.csv`. 받으면 지난번 근사값과 비교하고, 식물 30종 적합도를 새 값으로 다시 계산합니다.

## 바꿀 수 있는 값 (indoor_lux.py 위쪽 "여기만 확인하세요")
| 상황 | 바꿀 값 |
| --- | --- |
| 비확장 베란다(바깥창 + 안쪽창) | `LAYERS = 2` |
| Low-E 유리 | `GLASS_T = 0.65` |
| 방충망 있음 | `SCREEN = 0.75` |
| 창 크기가 다름 | `WIN_W`, `WIN_SILL`, `WIN_HEAD` (m) |
| 적합도에 쓸 위치를 창가로 | `MAIN_POSITION = '창가'` |
| 시나리오 A-2처럼 다른 결과 파일 | `MONTHLY_CSV = r'...\window_sun_A2_monthly.csv'`, `DETAIL_CSV = r'...\window_sun_A2_detail.csv'` |

## 계산이 하는 일 (한 줄 요약)
기상청 일사량을 직사광/산란광으로 나누고, 직사광은 window_sun이 "햇빛 들어옴"으로 판정한 시각에만 넣고, 산란광은 앞 건물에 가린 만큼 빼서, 유리 투과율과 창에서의 거리를 반영해 Lux로 바꿉니다. 자세한 식과 근거는 문서 「실내식물 Lux 추정 방법과 광 요구량 정리」에 있습니다.
