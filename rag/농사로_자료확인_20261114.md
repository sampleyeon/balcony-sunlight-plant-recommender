# 농사로 자료 확인 (2026-11-14)

## 0. 먼저 바로잡을 점

- plant_data.csv에서 **실내식물은 21～30번**(금전수～골드크레스트)이고, 1～10번은 채소·열매채소입니다.
- 그래서 "API로 되는 10종" = 21～30번, "따로 모아야 하는 20종" = **1～20번 (채소 6, 열매채소 4, 허브 10)** 입니다. (허브는 9종이 아니라 10종)

## 1. 확인 방법과 한계

- 농사로(nongsaro.go.kr)는 자동 접속을 막아 두어서(robots.txt) 제가 페이지를 직접 열 수 없었습니다.
- 그래서 아래 내용은 ① 검색엔진에 잡힌 농사로 페이지 제목, ② 공공데이터포털(data.go.kr) 설명, ③ 제가 원래 알고 있던 농사로 구조를 합친 것입니다.
- 표의 "확인" 칸: **확인** = 검색 결과로 페이지가 실제로 있음을 봄 / **거의 확실** = 농사로 구조상 있을 가능성이 매우 높음 / **불확실** = 직접 열어 봐야 함.
- 서연이 브라우저로 농사로 통합검색에 이름을 넣어 보면 1종당 1분 안에 확정할 수 있습니다 (3장 참고).

## 2. 농사로 API 범위

### 실내정원용 식물 API (21～30번이 여기서 옴)
- 공공데이터포털: https://www.data.go.kr/data/15059042/openapi.do (농촌진흥청_실내정원용 식물)
- 서비스 주소(농사로 API 센터): `http://api.nongsaro.go.kr/service/garden/gardenList`, `gardenDtl` (API 키 필요)
- 범위: 약 200여 종의 **관엽식물·화분 꽃식물** (홍콩야자, 몬스테라, 스킨답서스, 산세베리아 같은 종류). **상추·고추 같은 채소나 허브는 없음.**
- 항목: 광요구도(낮은 300～800 / 중간 800～1,500 / 높은 1,500～10,000 Lux), 생육온도(16～20℃, 21～25℃ 같은 구간), 겨울 최저온도, 계절별 물주기, 습도, 비료, 병충해, 관리 난이도 등.
- 우리 plant_data의 300/800/1500 lux, 16～20/21～25℃ 값이 이 구간과 정확히 같아서, 21～30번은 이 API에서 온 값으로 보입니다.
- 참고: 같은 계열로 "건조에 강한 실내식물"(https://www.data.go.kr/data/15058298/openapi.do), "공기정화식물"(https://www.data.go.kr/data/15063505/openapi.do) API도 있음. 모두 관엽식물 위주.

### 채소·허브를 다루는 농사로 자료
- 채소·허브는 **"실내정원용 식물"처럼 숫자가 칸별로 정리된 API는 없습니다.** 대신 글(문서) 형태 자료가 있습니다.
  - **농업기술길잡이**(작목별 표준영농교본 e-book): 예) http://www.nongsaro.go.kr/portal/ps/psb/psbx/cropEbookLst.ps?menuId=PS65290 — 생육적온, 파종·정식 시기, 병해충이 본문에 있음.
  - **작목정보(작목별 재배기술)**: 주소 형태 https://www.nongsaro.go.kr/portal/farmTechMain.ps?menuId=PS65291&stdPrdlstCode=품목코드
  - **농작업일정**: https://www.nongsaro.go.kr/portal/ps/psb/psbl/workScheduleLst.ps?menuId=PS00087 (월별 파종·수확 일정)
  - **도시농업 > 텃밭/옥상정원** 콘텐츠 (예: 옥상허브정원 https://www.nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS03169)
- RAG는 글을 잘라서 넣는 방식이라, 글 형태 자료도 충분히 쓸 수 있습니다. 다만 엔진(점수 계산)에 쓰는 숫자는 지금 plant_data 값을 그대로 둡니다.

## 5. 베란다 환경 개선 자료 (창 거리별 빛, 식물등)

### (가) 창과의 거리별 빛
- 농사로·농촌진흥청에서 "창에서 몇 m면 몇 lux" 같은 일반 표는 찾지 못했습니다.
- 대신 **우리 indoor_lux.py가 집마다 창가/1m/2m/3m lux를 직접 계산**하므로, 일반 표보다 정확한 자기 데이터가 이미 있습니다.
- 기준값은 실내정원용 식물 API의 광요구도 구간(300 / 800 / 1,500 lux)을 쓰면 출처가 분명합니다.
- 결론: **넣을 수 있음** (우리 계산값 + 농사로 광요구도 기준).

### (나) 식물등 밝기와 켜는 시간
- 한국 공공자료: 농촌진흥청 LED 보도자료(2009, https://www.korea.kr/briefing/pressReleaseView.do?newsId=155331734)는 온실용이라 가정용 숫자가 없습니다.
- 쓸 수 있는 공개 자료: 미시간주립대 Runkle 교수 자료
  - 하루 필요한 빛의 양(DLI): 잎채소·허브 12 이상, 관엽식물 6～10, 열매채소 15 이상 — https://www.canr.msu.edu/floriculture/uploads/files/dli%20requirements.pdf
  - 상추 12～14, 밤에 4～6시간은 꺼서 어둡게 — https://bluedynamo.msu.edu/uploads/resources/pdfs/lightingvegetables.pdf
- 계산 방법 (출처 있는 공식):
  - DLI = PPFD(빛 세기) × 켜는 시간(h) × 0.0036
  - 부족한 DLI = 목표 DLI − 지금 자리의 DLI (indoor_lux에서 계산)
  - 켜는 시간 = 부족한 DLI ÷ (식물등 PPFD × 0.0036), 최대 18시간
  - 예: 2m 자리 DLI 3, 바질 목표 12 → 부족 9. 식물등이 30cm에서 PPFD 200이면 9 ÷ (200×0.0036) ≈ 12.5시간
- 주의: 식물등의 PPFD는 **제품마다 다르고 상자·설명서에 적혀 있음**. 공공 데이터가 아니라서, 앱에서는 "예시 값(예: 30cm에서 PPFD 200)"으로 보여주거나 사용자가 입력하게 하는 게 정직합니다.
- 결론: **넣을 수 있음** (해외 대학 자료 + 우리 계산, 등 밝기는 예시값으로 표시).

## 7. 농사로 옥상허브정원 (서연이 찾음, rag/농사로_옥상허브정원.pdf)

- 주소: https://www.nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS03169
- 작물별 카드가 있는 허브: **라벤더, 레몬밤, 민트, 로즈마리, 타임** (+ 셀러리 잎)

- 없는 항목: 빛(광), 생육온도 범위, 물주기
- 이름만 나오는 허브: 바질, 고수(코리앤더), 딜, 차이브, 파슬리 → 재배 정보는 없음
- PDF가 그림이라 글자를 뽑을 수 없음 → 카드 6개는 짧으니 직접 옮겨 적는 게 빠름
- 남은 것: 바질(농사로 질의응답 글 있음), 고수, 딜, 차이브, 루꼴라
